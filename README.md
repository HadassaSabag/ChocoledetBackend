ברוכים הבאים ל-**Chocoledet Backend**! <br/>
 זהו צד השרת של חנות האונליין למוצרי אמהות "Chocoledet", המספק את כל הלוגיקה העסקית, ניהול הנתונים וה-APIs עבור אפליקציית ה-Frontend.

### 📝 אודות הפרויקט

ה-Backend של Chocoledet נבנה ב-**C# עם NET.** , ומשמש כעמוד השדרה של החנות. </br>
הוא מטפל בניהול קטלוג המוצרים, עיבוד הזמנות, אינטגרציה עם בסיס נתונים SQL, וניהול חשבונות משתמשים.</br>
המערכת עוצבה להיות אמינה, מאובטחת וקלה להרחבה, תוך מתן מענה ספציפי לצרכים של חנות מקוונת למוצרי אמהות.

### 🚀 תכונות עיקריות

* **ניהול מוצרים**: API מלא לניהול קטלוג המוצרים (הוספה, עריכה, מחיקה, שליפה).
* **ניהול הזמנות**: לוגיקה לעיבוד הזמנות, סטטוסי הזמנה וארכיון הזמנות.
* **ניהול משתמשים**: ניהול חשבונות אישיים למשתמשים, העדפות אישיות ופרטי התחברות מאובטחים.
* **אינטגרציה עם SQL Database**: אחסון מאובטח ויעיל של נתוני מוצרים, משתמשים והזמנות.
* **API מאובטח**: נקודות קצה (Endpoints) מאובטחות לתקשורת עם ה-Frontend.

### 🛠️ טכנולוגיות

* **C#**
* **.NET** ( ASP.NET Core עבור Web API)
* **SQL Server**
